# 채택 모델·라이선스 원장

아직 어떤 베이스 모델·스타일 LoRA·로컬 LLM도 채택하지 않았다. 아래 칸은 사람이 각
라이선스 원문을 읽고 상업 이용 조건을 확인한 뒤 채운다. 오픈웨이트라는 사실만으로
상업 이용 가능하다고 판단하지 않는다.

| 역할 | 이름 | 버전·리비전 | 라이선스 이름 | 라이선스 원문 URL 또는 저장 경로 | 상업 이용 가부·제한 | 확인일 | 확인 근거·확인자 |
|---|---|---|---|---|---|---|---|
| 베이스 모델 | 미선정 |  |  |  |  |  |  |
| 스타일 LoRA | 미선정 |  |  |  |  |  |  |
| 로컬 LLM | 미선정 |  |  |  |  |  |  |

`scripts/gen_prompts.py`의 기본값 `qwen3:8b`는 RTX 5080 16GB에서 실행 가능한 범위를
보장하기 위한 실행 기본값일 뿐, 위 원장에 기록된 채택 모델이 아니다. 실제 생성에 쓴
모델·태그·라이선스 원문은 프롬프트 결과를 커밋하기 전에 이 표에 기록한다.

# 아트 파이프라인

이 디렉터리는 사람이 수집·학습·생성할 때 재현에 필요한 가벼운 입력만 고정한다.
모델 선택과 공공누리 유형 확인은 사람이 원문을 검토한 뒤에만 진행한다.

커밋 대상은 워크플로 API JSON, kohya_ss 설정, 프롬프트 템플릿·네거티브 프롬프트,
고정 시드, 출처 원장, 실행 스크립트다. 원본·학습 크롭·가중치·체크포인트·생성 이미지는
`.gitignore` 대상이며 별도 백업으로 보관한다.

| 경로 | 역할 |
|---|---|
| `MODEL.md` | 실제 채택 전 사람이 기록하는 모델·라이선스 원문 원장 |
| `dataset/` | 출처 원장과 수집·학습 데이터의 로컬 보관 규칙 |
| `lora/` | kohya_ss 재학습 설정과 로컬 가중치 보관 규칙 |
| `workflows/` | ComfyUI API 워크플로 템플릿과 생성 고정값 |
| `prompts/` | 버전 관리되는 프롬프트 계약 |
| `raw/`, `final/` | 생성 후보·선별 결과의 로컬 보관 규칙 |
| `picks.txt` | 사람이 후보를 고른 카드·파일·시드를 기록하는 원장 |

`scripts/gen_prompts.py`는 저장소 루트의 `scripts/`에 있다. 카드 데이터에서 대상 묘사
근거를 만들고, Ollama 생성과 Ollama 없는 검증을 별도 명령으로 제공한다.
